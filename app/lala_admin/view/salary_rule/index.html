工资计算公式

工资 = 底薪 + 提成 + 奖金 + 全勤奖 - 扣款
  • 底薪：固定月薪
  • 提成：根据新增/历史客户流水按比例计算
  • 奖金：绩效奖金等
  • 全勤奖：当月无迟到/早退/请假，奖励200元
  • 扣款：迟到/早退每次扣50元等
